# 配置说明

## 配置优先级

程序先读取 `CONFIG_PATH` 指向的 JSON 文件，再用环境变量覆盖同名配置。Docker Compose 将 `CONFIG_PATH` 设置为 `/app/configs/config.docker.json`，同时注入数据库和中间件密码等环境变量。

| 文件 | 适用场景 | MySQL 地址 |
| --- | --- | --- |
| `config.compose-local.json` | MySQL/Redis/RabbitMQ 在 Docker，API/Worker 用本机 `go run` | `localhost:3307` |
| `config.docker.json` | 五个服务均由 Docker Compose 启动 | `mysql:3306` |

JSON 不支持注释。`.env` 用于本机密钥和密码，不应提交；`.env.example` 只提供可复制的开发模板。

## 常用环境变量

| 变量 | 作用 |
| --- | --- |
| `CONFIG_PATH` | 配置 JSON 路径 |
| `MYSQL_DATABASE` / `MYSQL_ROOT_PASSWORD` | MySQL 数据库名和密码 |
| `REDIS_PASSWORD` | Redis 密码 |
| `RABBITMQ_USER` / `RABBITMQ_PASS` | RabbitMQ 凭证 |
| `JWT_SECRET` | JWT 签名密钥；生产环境必须替换为高强度随机值 |
